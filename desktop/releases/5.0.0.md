# ZenithW Desktop 5.0.0

**A new foundation. The same simple way to save media.**

**Windows 10/11 (x64)** · **Rust + WebView2** · **Installer and portable ZIP**

ZenithW Desktop 5.0 is the biggest architectural change to the Windows app so far. The Electron-based desktop host has been replaced with a native Rust/Tauri backend and Microsoft Edge WebView2. The goal is straightforward: a smaller Windows package, a more maintainable core, and a cleaner experience without sacrificing download controls.

This isn't a fresh coat of paint on the same old engine. A significant part of the desktop application has been rebuilt, while the features people already use remain available.

## What's Changed

### 1. Goodbye Electron. Hello Rust.

- **Rust now runs the desktop backend**, including the download queue, local file operations, settings, and management of media-tool processes.
- **Microsoft Edge WebView2 renders the interface** instead of bundling Electron's Chromium and Node.js runtime.
- **Download cancellation handles child processes**, so stopping a job also stops the media tools it started.
- **The Windows installer is approximately 116.5 MB**, around **46% smaller than the 4.2 release**.

A smaller installer is measurable; a universal performance miracle is not. Startup, memory consumption, download speed, and conversion time still depend on the computer, source site, network, and workload.

### 2. A cleaner, more comfortable interface

The workspace has been refreshed without turning a straightforward downloader into a cockpit.

- Updated link input, buttons, selection states, and spacing.
- **White, Black, and Neon Purple themes**, plus an option to follow the Windows theme.
- Improved keyboard focus visibility and controls.
- Searchable, categorized settings with more consistent switches and navigation.
- Support for the system's reduced-motion preference.

There are also more useful **About** and **What's New** sections inside the app, available in English, Turkish, German, and Russian.

### 3. Your download tools are still here

The backend changed; ZenithW hasn't suddenly forgotten how to download a video.

- Download supported video and audio formats, with quality and container options where the source allows them.
- Prepare multiple links, use download queues, and select items from playlists.
- Trim media, work with subtitles and metadata, and manage cover artwork.
- Use optional SponsorBlock, proxy settings, and supported cookie-session workflows.
- Organize work with local profiles and persistent download history.
- View the yt-dlp engine version and choose an available update channel in Settings.

These are **continuing capabilities**, not features invented for 5.0. Their behavior and availability still depend on the media source and the tools involved.

### 4. Upgrading from 4.x

The 5.0 installer uses the existing application identity and installation location. It can replace the older Electron application while cleaning up legacy application-owned runtime files.

Your existing **settings, profiles, download history, download archive, and exported session cookies** remain readable. The in-app browser login uses a new WebView2 profile, however, so **some websites may ask you to sign in again**.

Existing downloads are not automatically re-downloaded. Interrupted jobs aren't guaranteed to resume after a restart.

### 5. Privacy, packaging, and reliability

ZenithW still downloads directly from the source using **your computer's connection**. Media processing runs locally through tools such as yt-dlp, FFmpeg, FFprobe, aria2, and Deno. Files are not routed through the ZenithW web download service.

- Settings and history are kept on the device.
- Settings exports exclude sensitive cookie and private connection data.
- The new packaging process checks bundled media tools and produces published SHA-256 checksums.
- The installer uses a **per-user Windows installation** and can install WebView2 if the runtime is missing.
- Optional integrations, update checks, and source requests may contact their respective services.

No ZenithW account, subscription, or ads are required.

## Download & Installation

Choose one of the assets below.

| File | What it's for |
| --- | --- |
| **Zenith-5.0.0-Windows-Setup.exe** | Standard Windows installation with shortcuts; recommended for most users |
| **Zenith-5.0.0-Windows.zip** | Portable version; extract the entire archive, then launch `Zenith.exe` |
| **SHA256SUMS.txt** | Checksums for verifying downloaded packages |

**System requirement:** Windows 10 or Windows 11, 64-bit. The interface requires Microsoft Edge WebView2 Runtime. The setup installer checks for it.

For the ZIP edition, don't run the EXE directly from inside the archive. Extract **all** files first so the bundled media tools are available.

## Good to Know

- A source may restrict downloads, available formats, subtitles, or access to account-only media. ZenithW doesn't override those restrictions.
- Some media operations can take time even with the new Rust backend. FFmpeg and yt-dlp still do the actual work.
- Browser sessions may require a fresh login after migration from Electron to WebView2.
- If you're updating from an older version, close the running app before installing 5.0.
