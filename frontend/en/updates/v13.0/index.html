v13.0 August 2026

faster downloads with smarter and safer file processing

v13.0 makes the download chain faster, more consistent, and more resilient under load.

YouTube compatibility has been refreshed while internal infrastructure details stay out of the way. Bulk downloads, mute video, remuxing, conversion, and file delivery all received practical improvements.

more reliable YouTube downloads

ZenithW now follows recent YouTube changes more reliably. Unnecessary retries are reduced during temporary restrictions, and technical failures are presented as clearer messages.

bulk downloads are now accurate and lighter

Bulk mode no longer performs an unnecessary information request for every link. Completed items are counted correctly and files move directly into the browser download flow.

mute mode downloads video only

On compatible sources, the audio stream is no longer downloaded only to be removed later. This reduces network use, processing time, and temporary disk demand.

real remux and smarter conversion

The remux tool now performs a real container change. Compatible video and audio streams are copied without quality loss, with re-encoding used only when required.

bounded storage and native file delivery

Prepared files, temporary storage, and simultaneous transfers now stay within defined limits. Large files download through short-lived links instead of being copied into browser memory.

faster repeat visits

The main application code, updates page, and shared styles now use separate versioned assets. Browsers can reuse unchanged files, making repeat visits lighter.

In short, v13.0 brings less wasted work, more accurate results, and a stronger foundation that stays out of the user’s way.
