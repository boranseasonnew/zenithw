01 / WHAT IS ZENITHW?

An independent, open-source media workspace.

ZenithW; is a standalone web tool that analyzes a supported video or audio link, shows the available quality and formats, prepares the selected media and delivers it to the browser. The aim is to provide a clear download experience without fake download buttons, ad redirects and unnecessary membership steps.

The project is not just about downloading links. It combines features such as video and audio formats, batch downloading, lossless remux, file conversion, metadata, subtitles and processing progress in one simple interface. ZenithW is not a media archive or social network; It is a temporary tool that completes the user's desired action.

02 / HOW DOES IT WORK?

A controlled flow from connection to delivery.

The sent link is first passed through security and supported platform rules. Backend receives media information from the resource provider; It finds suitable streams with yt-dlp and performs merging, remuxing or converting when necessary with FFmpeg. Progress is transferred to the interface via Socket.IO. The ready file is presented to the same user with a timed and disposable transfer link.

Transaction files are not maintained as persistent content storage. Once the successful transfer is complete, the file is cleared; Unfinished or erroneous jobs are also removed with a periodic cleaning mechanism. This design both limits disk usage and prevents unnecessary media accumulation.

03 / IS IT SAFE?

Trust is built with verifiable boundaries, not slogans.

ZenithW does not require user account or payment information; does not aim to run advertising scripts and third-party tracking pixels on the download page. Production traffic is forwarded via HTTPS to Cloudflare, and from there to the Amazon EC2 backend with only a verified origin connection. Source URL controls, SSRF protection that prevents access to private network addresses, file and time limits, request rate limits and temporary file cleaning are among the defense layers of the backend.

However, the promise of “zero risk” is not honest for any service operating on the Internet. The browser, Cloudflare, AWS, source platform, and open source components used are separate trust boundaries. The ZenithW is not designed to store private or sensitive connections as a secret safe. Users should only process content they have the right to access and download; They must make their own risk assessment for personal or confidential media.

04 / PRIVACY

What is processed, what is stored, what guarantee is given?

When a transaction is initiated, the connection, technical request information and IP address pass through the Cloudflare and AWS infrastructure for the service to operate. IP address may be used for abuse and concurrent transaction limits; Error and access records can be viewed in infrastructure logs for operational security purposes. The source platform also enforces its own connection and log policies.

Download history is not tied to the server account; It is kept in the browser's local storage and can be deleted from the history page. Prepared media files are not saved to the permanent user profile. The server cookie used for YouTube is the technical access file of the site administrator; visitor's browser cookies are not uploaded to ZenithW.

Is confidentiality guaranteed?

Absolute anonymity or “no data is processed” cannot be guaranteed. The commitment is more concrete: it is aimed not to create unnecessary user accounts, not to permanently archive media files, to keep the history local and not to misuse the data required for security. For detailed and up-to-date rules, the privacy page is taken as basis.

05 / HOW CAN YOU TRUST?

Pay attention to what you can control, not what is said.

  • Check the domain name: The official interface only works via zenithw.space and api.zenithw.space.
  • Check out the code: The source code, request flow, and security checks can be viewed at GitHub.
  • Query permissions: ZenithW does not require you to create a browser password, payment information or personal account for normal downloading.
  • Manage local data: You can delete your download history and clear browser site data whenever you want.
  • Be cautious with sensitive content: Do not send links you have no right to access, or links that must remain confidential, to any online download service.
