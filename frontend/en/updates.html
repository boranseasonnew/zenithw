v17.2 November 24, 2026

Vimeo guidance, clearer download status and updated tooling

For Vimeo links, the web app now explains the current limitation before starting a download attempt. This release also updates the yt-dlp dependency to its latest stable version and brings together interface refinements based on recent user feedback.

This is a web release update. It does not mean Vimeo access has changed or that every link can be downloaded. Signing in to Vimeo in the built-in browser in the Windows or Android app has not been tested and is not guaranteed to work. Session cookies remain on the device and are sent to Vimeo for authentication.

Know the Vimeo limitation upfront

After Continue is pressed for a valid Vimeo URL, an explanation opens instead of the download dialog, and no analysis request is sent to the web service. The notice also links to the Windows and Android apps. We will follow stable yt-dlp updates and review Vimeo support again as it changes.

yt-dlp updated to the latest stable release

The backend dependency lock now pins yt-dlp 2026.11.23. This is a dependency update, not a claim that Vimeo links now work. The new version takes effect when the backend packages are updated.

Homepage refinements from feedback

The app promotion that opened automatically on the homepage has been removed. The Vimeo notice appears only after the user chooses to submit a link. English title and preview metadata are also aligned with the English homepage.

Thanks for the feedback. This release also includes related refinements to keep supported-platform names and interface guidance consistent.
