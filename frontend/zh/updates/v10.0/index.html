v10.0 2026 年 8 月

大型后端维护通行证：安全性、稳定性和清理

滚动查看发生了什么变化

这个对你来说基本上是不可见的，但它在幕后发生了很大的变化。我们一次性清理了服务器端积累的一批安全问题、稳定性错误以及旧的/被遗忘的代码。

亮点：修复了 Cloudflare 背后的真实客户端 IP，以便正确读取，关闭可能被外部滥用的 SSRF/DNS 重新绑定漏洞，并消除随着时间的推移而积累的内存/计数器泄漏。

Cloudflare IP检测及安全加固

由于之前后端基础设施的内部代理层，我们的服务器有时会误读真实的 Cloudflare IP，甚至拒绝合法请求。我们使用 ProxyFix 中间件修复了此问题，并确保 CORS 预检（选项）请求也正确通过该检查。我们还关闭了一个 SSRF/DNS 重新绑定漏洞，该漏洞可能会欺骗我们的服务器向内部网络发出请求 - 我们删除了启用它的旧下载帮助程序 (aria2c)，并强化了检查出站网络请求的套接字级防护。

稳定性：修复了泄漏和超时不匹配问题

用于随着时间的推移缓慢积累内存的速率限制器；我们将其替换为自动过期的 TTLCache。在某些错误路径中，每个 IP 的并发请求计数器可能会卡住而不重置 - 已修复。我们还阻止了下载队列计数器偶尔降至零以下的情况。服务器现在由 2 个工作线程（而不是 1 个）运行，并且子进程使用与 Gunicorn 自己的超时设置相协调的实际超时。

代码清理和小修复

所有依赖项现在都固定到固定版本（以避免意外升级），删除了重复导入和未使用的空函数，文件清理现在记录其操作并按正确的计划运行。修复了静音功能中的文件扩展名检测错误，并且 ffmpeg 现在以跨平台方式定位。所有服务器日志都从土耳其语翻译成英语，并且 socketio 通知现在通过防错包装器 (safe_emit)。

简而言之：此更新的大部分内容是不可见的，但它使我们的服务器更安全、更稳定。
