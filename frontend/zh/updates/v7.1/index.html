ZenithW 现在就在您的口袋里：移动应用程序已上线

滚动查看发生了什么变化

我们一直想发布的事情终于发生了：官方 ZenithW Android 应用程序已准备就绪，可以直接从 GitHub 下载。无需打开浏览器或处理选项卡 - 现在您的手机上也有相同的快速下载引擎。

我们在下面列出了推荐它的原因以及它提供的功能。简而言之：通过您自己的 IP 下载、SponsorBlock、字幕支持、aria2 速度引擎、cookie 支持和 0% 错误率缩略图下载。

移动应用程序已上线

您现在可以从 GitHub 发布页面直接下载 ZenithW 的 Android 应用程序作为 APK。它使用与网络版本相同的基于 yt-dlp 的下载引擎，不同之处在于下载是通过您自己的设备连接而不是我们的服务器运行的。查看新的“移动应用程序”页面了解详细信息和下载链接。

通过自己的IP下载

与网络版本不同，移动应用程序中的下载通过您自己的连接运行。这意味着更多的隐私和更少的平台端速率限制。

SponsorBlock、字幕和 aria2

SponsorBlock 支持自动跳过赞助商片段、视频旁边的字幕下载以及明显更快的多连接 aria2 下载引擎，这些都已准备好在应用程序中使用。

cookie 支持和 0% 错误率

您可以为登录控制内容添加您自己的 cookie。下载也经过彻底测试，运行无错误，您只需点击一下即可单独抓取视频的缩略图。

开源

就像网络版本一样，移动应用程序的源代码在 GitHub 上公开 - 请随意查看或贡献。

简而言之：ZenithW 不再局限于浏览器 - 只需轻轻一按即可。
