v15.0 使 ZenithW Web 体验的界限更加清晰。 Web 服务中禁用 YouTube 访问；此更改仅涉及网站。桌面应用程序是一个单独的产品。

“关于”和“更新”页面现在具有更易读的布局。项目链接也已移至当前的 GitHub 帐户和存储库。

YouTube 网络访问被禁用

YouTube 链接不通过 Web 界面进行处理。其他受支持的源和桌面应用程序具有单独的行为。

GitHub 链接现在指向当前帐户

主要项目存储库是 boranseasonnew/zenithw; Android 应用程序位于 boranseasonnew/zenithw-android。使用这些地址获取源代码和版本。

信息页面已完善

“关于”部分具有更易读的文本和更清晰的导航。现在，积分将人员、开源工具和许可证分开。更新已成为更简单的黑白发布日志。

安全边界更加牢固

链接验证、请求限制和媒体处理方面的保护措施已得到审查。可以在源代码和关于部分检查安全方法。

v15.0 使支持的行为和项目所有权更容易理解。新的 GitHub 存储库中提供了当前源代码和发布链接。
