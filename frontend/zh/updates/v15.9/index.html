v15.9 2026年10月12日

全新下载页面，更清晰的 ZenithW。

v15.9 汇集全新下载页面、Android 教程和简洁的版本档案。近期支持页面及移动性能改进也记录在 v15.3–v15.8 的说明中。

重新设计的下载页面

哑光黑灰界面、官方彩色平台标志、均衡卡片和简短交互动画。移动端提供 Windows 与 Android 标签，桌面端便于比较。Windows 4.1.0 和 Android 2.1.3 的下载方式集中展示。

无需离站的 Android 教程

教程卡片会打开 16:9 视频窗口。仅在点击后通过 youtube-nocookie.com 创建播放器，关闭时完全移除。支持 ESC、点击窗口外部和关闭按钮，并恢复键盘焦点。

更易阅读的版本说明

更新页面采用清晰字体、细分隔线和舒适间距重新设计。v15.3–v15.9 快速档案与全部旧版本选择菜单并存。无需 JavaScript 也能阅读，支持八种语言及响应式布局。
