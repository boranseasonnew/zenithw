下载前拒绝不安全的媒体协议

在此版本中

01显式媒体协议白名单02第二个 FFmpeg 防御层

滚动查看发生了什么变化

即使输入以 http 或 https 开头，提取的媒体流也可能解析为不同且不安全的协议。该协议决定现已单独验证。

显式媒体协议白名单

仅接受 HTTP、HTTPS、本机 HLS 和 DASH 流。 RTMP 和需要外部网络下载程序的类似路径会因安全错误而停止。

第二个 FFmpeg 防御层

如果 yt-dlp 仍然通过兼容路径到达 FFmpeg 下载器，则其输入参数拒绝远程网络协议。后处理也仅限于本地。

简而言之：URL 安全是在真实媒体协议上强制执行的，而不仅仅是第一个链接。
