更新的应用程序、刷新的页面和更多语言

v15.2刷新了Windows和Android应用程序下载页面并加强了网络安全措施。请点击下面的链接获取更新的应用程序。

现已提供俄语、越南语、简体中文和日语。您的语言选择也会贯穿更新、指南和信息页面。

刷新的应用程序页面

Windows 和 Android 应用程序页面采用了全新设计，让您可以更轻松地探索设备的功能和下载。 Windows 应用页面 · Android 应用页面.

网络安全

网络版加强了安全措施。链接、内容和文件处理检查使下载流程受到更严格的控制。

更新了 Windows 和 Android 应用程序

Zenith Windows 4.0 和 Android 2.1 可供选择。 Android 2.1 包括夜间引擎更新修复、保存的首选项和最小的下载屏幕。从以下位置获取安装程序 Windows 和 Android 页。

网站上有八种语言

俄语、越南语、简体中文和日语以及土耳其语、英语、法语和德语。发行说明、指南、应用程序页面和信息页面与菜单一起翻译。当您在页面之间移动时，您选择的语言将被保留。
