v11.1 2026 年 8 月

yt-dlp 流量现在保留在受保护的本机路径上

在此版本中

滚动查看发生了什么变化

为了使 Python SSRF 防护保持有效，下载引擎的网络连接现在通过相同的保护层。

HLS 和 DASH 的本机下载器

HTTP、HTTPS、HLS 和 DASH 下载是通过 yt-dlp 的本机下载器强制进行的，从而使 DNS 和套接字检查对于每个远程连接都保持活动状态。

禁用支持网络的外部下载器

早期的 aria2c 限制已得到扩展：FFmpeg 无法再作为下载程序打开远程 URL，并且仅可用于本地合并和转换工作。

简而言之：现在每个下载引擎路径都遵循相同的网络安全规则。
