YouTube リンクがアプリを指すのはなぜですか?

YouTube ダウンロードは、現在、ZenithW Web バージョンでは無効になっています。 YouTube リンクを入力すると、Android または Windows アプリで続行する方法が提供されます。

現在の Web の制限

ソース プラットフォームによってサーバー IP アドレスに制限が適用されると、デバイスからのアクセスが Web サーバー経由のアクセスとは異なる場合があります。そのため、ZenithW Web では、ダウンロード キューに YouTube リンクを追加する代わりに、アプリ オプションを提供しています。

これは、Web ダウンローダー全体が利用できないという意味ではありません。 Web サービスを通じてアクセスできる他のサポートされているソースも引き続き使用できます。

Android アプリと Windows アプリの違い

アプリはデバイスのインターネット接続を通じてソースにアクセスします。これは、Web バージョンで使用されるサーバー接続とは別のパスです。

この違いは、すべての YouTube 動画の成功を保証するものではありません。ビデオ アクセス、利用可能な形式、地域、接続条件も結果に影響します。アプリは、ソースにない品質オプションや権限を作成できません。

アプリで続行

  1. デバイスの公式 ZenithW アプリ ページを開き、そこにリストされている現在のダウンロード リンクを使用します。
  2. YouTube ビデオまたはサポートされている共有リンクをコピーします。
  3. それをアプリに貼り付け、ソースから利用できるビデオまたはオーディオのオプションを確認します。
  4. 出力を選択し、ダウンロードを開始します。エラーが発生した場合は、エラー メッセージとリンクが通常のブラウザで開くかどうかを確認してください。

ファイルと品質の選択

音声付きビデオ、音声のみ、またはプレーヤーに適した形式を選択します。利用可能な解像度はソースによって異なります。すべてのリンクが 4K または特定のオーディオ品質を提供することを期待しないでください。

ファイルが再生できない場合は、そのコンテナとコーデックを検討してください。ストリームに互換性がある場合は再多重化が機能する場合がありますが、コーデックを変更するには変換が必要になる場合があります。
