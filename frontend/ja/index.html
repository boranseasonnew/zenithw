使い方は？

  1. プロフィールアドレスの代わりに保存したい投稿のリンクをコピーします。
  2. リンクを貼り付けて続行します。ビデオとオーディオには自動を使用し、オーディオのみにはオーディオ モードを使用します。
  3. ダウンロードプランを確認してダウンロードしてください。利用可能な品質は、ソース共有によって提供されるストリームによって異なります。

よくある質問

ZenithW は無料ですか? それともアカウントが必要ですか?

Web ツールは無料で、ZenithW アカウントを開く必要はありません。ソース プラットフォームのアクセス制限は引き続き適用されます。

YouTube リンクは Web 上で機能しますか?

YouTube のダウンロードは現在 Web 版で終了しています。 Android または Windows アプリのデバイス接続経由で試すことができます。再度アクセスできるかどうかは、ビデオとソースの状況によって異なります。

非公開の投稿や削除された投稿はダウンロードできますか?

リソースにアクセスできない場合、ファイルを準備できません。ブラウザで開いているアカウントは、そのセッションを Web サーバーに自動的に転送しません。

変換と再多重化の違いは何ですか?

再エンコードせずに Remux 互換ストリームをトランスポートします。変換は、別のコーデックが必要な場合に使用されます。 フォーマットと互換性のガイドをお読みください。
