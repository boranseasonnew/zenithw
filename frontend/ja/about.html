ZenithW は、不要なリダイレクトを行わずにビデオとオーディオのリンクをダウンロード可能なファイルに変換する独立した Web ツールです。

01 / 天頂とは？

独立したオープンソースのメディア ワークスペース。

ZenithW;は、サポートされているビデオまたはオーディオ リンクを分析し、利用可能な品質と形式を表示し、選択したメディアを準備してブラウザに配信するスタンドアロン Web ツールです。目的は、偽のダウンロード ボタン、広告のリダイレクト、不要なメンバーシップ手順を排除した、明確なダウンロード エクスペリエンスを提供することです。

このプロジェクトは、リンクをダウンロードするだけではありません。ビデオおよびオーディオ形式、バッチダウンロード、ロスレスリマックス、ファイル変換、メタデータ、字幕、処理の進行状況などの機能を 1 つのシンプルなインターフェイスに組み合わせています。 ZenithW はメディア アーカイブやソーシャル ネットワークではありません。これは、ユーザーの希望するアクションを完了するための一時的なツールです。

02 / どのように機能するのですか?

接続から配送までの制御されたフロー。

送信されたリンクは、まずセキュリティとサポートされているプラットフォーム ルールを通過します。バックエンドはリソースプロバイダーからメディア情報を受け取ります。 yt-dlp で適切なストリームを見つけ、必要に応じて FFmpeg でマージ、再多重化、または変換を実行します。進行状況は Socket.IO 経由でインターフェイスに転送されます。準備ができたファイルは、時間指定された使い捨ての転送リンクを使用して同じユーザーに提示されます。

トランザクション ファイルは永続的なコンテンツ ストレージとしては維持されません。転送が正常に完了すると、ファイルはクリアされます。未完了のジョブや間違ったジョブも定期的なクリーニング メカニズムによって削除されます。この設計により、ディスクの使用が制限され、不必要なメディアの蓄積が防止されます。

03 / 安全ですか?

信頼はスローガンではなく、検証可能な境界線によって構築されます。

ZenithW にはユーザー アカウントや支払い情報は必要ありません。ダウンロード ページで広告スクリプトやサードパーティの追跡ピクセルを実行することを目的としたものではありません。本番トラフィックは、HTTPS 経由で Cloudflare に転送され、そこから検証済みのオリジン接続のみを使用して Amazon EC2 バックエンドに転送されます。バックエンドの防御層には、ソース URL 制御、プライベート ネットワーク アドレスへのアクセスを防ぐ SSRF 保護、ファイルと時間の制限、リクエスト レート制限、一時ファイルのクリーニングなどがあります。

しかし、インターネット上で運営されているサービスにとって、「リスクゼロ」という約束は誠実ではありません。使用されるブラウザー、Cloudflare、AWS、ソース プラットフォーム、およびオープン ソース コンポーネントは、別個の信頼境界です。 ZenithW は、プライベートまたは機密の接続を秘密の金庫として保存するように設計されていません。ユーザーは、アクセスしてダウンロードする権利を持つコンテンツのみを処理する必要があります。個人メディアまたは機密メディアについては、独自のリスク評価を行う必要があります。

04 / プライバシー

何が処理され、何が保存され、どのような保証が与えられるのでしょうか?

トランザクションが開始されると、サービスが動作するために、接続、技術リクエスト情報、および IP アドレスが Cloudflare および AWS インフラストラクチャを通過します。 IP アドレスは悪用や同時トランザクション制限に使用される可能性があります。運用セキュリティの目的で、エラーとアクセスの記録をインフラストラクチャ ログで表示できます。ソース プラットフォームは、独自の接続ポリシーとログ ポリシーも適用します。

ダウンロード履歴はサーバー アカウントに関連付けられません。これはブラウザのローカル ストレージに保存され、履歴ページから削除できます。準備されたメディア ファイルは永続的なユーザー プロファイルには保存されません。 YouTube に使用されるサーバー Cookie は、サイト管理者の技術アクセス ファイルです。訪問者のブラウザの Cookie は ZenithW にアップロードされません。

機密性は保証されていますか?

絶対的な匿名性や「データが処理されない」ことは保証できません。この取り組みはより具体的で、不必要なユーザー アカウントを作成しないこと、メディア ファイルを永久にアーカイブしないこと、履歴をローカルに保存すること、セキュリティに必要なデータを悪用しないことを目的としています。詳細かつ最新のルールについては、プライバシー ページが基礎となります。

05 / どうして信用できるの？

何を言われるかではなく、自分がコントロールできることに注意を払いましょう。

  • ドメイン名を確認してください: 公式インターフェースは、zenithw.space および api.zenithw.space 経由でのみ機能します。
  • コードをチェックしてください: ソース コード、リクエスト フロー、セキュリティ チェックは、GitHub で参照できます。
  • クエリ権限: ZenithW では、通常のダウンロードではブラウザのパスワード、支払い情報、個人アカウントを作成する必要はありません。
  • ローカル データを管理します。 いつでもダウンロード履歴を削除したり、ブラウザ サイトのデータをクリアしたりできます。
  • 機密性の高いコンテンツには注意してください。 アクセスする権利のないリンクや、秘密にしておく必要があるリンクをオンラインのダウンロードサービスに送信しないでください。
