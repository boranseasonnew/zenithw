Séparateur audio IA

Séparer l’audio

Gratuit et open source MIT

Propulsé par Lilith Audio Engine

ZenithW utilise Lilith Audio Engine pour séparer l’audio dans votre navigateur. Écrit en TypeScript, le moteur fonctionne sur votre appareil avec WebGPU ou WebAssembly ; le fichier audio n’est pas envoyé à un serveur.

Le code original du moteur est sous licence MIT. Vous pouvez l’utiliser, le modifier et le partager, y compris commercialement, en conservant les mentions de copyright et de licence. Le modèle IA et les autres composants gardent leurs propres licences.
