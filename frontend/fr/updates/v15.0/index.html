Faites défiler pour découvrir ce qui a changé

La version 15.0 clarifie les limites de l'expérience Web ZenithW. L'accès à YouTube est désactivé dans le service Web ; ce changement concerne uniquement le site internet. L'application de bureau est un produit distinct.

Les pages À propos et Mises à jour ont désormais une présentation plus lisible. Les liens du projet ont également été déplacés vers le compte et les référentiels GitHub actuels.

L'accès à YouTube est désactivé sur le Web

Les liens YouTube ne sont pas traités via l'interface Web. Les autres sources prises en charge et l'application de bureau ont un comportement distinct.

Les liens GitHub pointent désormais vers le compte courant

Le référentiel principal du projet est boranseasonnew/zenithw; l'application Android est disponible à boranseasonnew/zenithw-android. Utilisez ces adresses pour le code source et les versions.

les pages d'informations ont été affinées

La section À propos contient un texte plus lisible et une navigation plus claire. Les crédits séparent désormais les personnes, les outils open source et les licences. Les mises à jour sont devenues un journal de publication plus simple en noir et gris.

les frontières de sécurité sont plus fortes

La validation des liens, les limites de requêtes et les garanties concernant le traitement des médias ont été revues. L’approche de sécurité peut être inspectée dans la section source et À propos.

La version 15.0 facilite la compréhension des comportements pris en charge et de la propriété du projet. Les liens vers les sources et les versions actuelles sont disponibles dans les nouveaux référentiels GitHub.
